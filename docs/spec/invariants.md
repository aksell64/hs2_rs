# Инварианты для Quint (consensus-ядро HotStuff-2, chained)

Область: только consensus-ядро (createLeaf / update / onReceiveProposal / onReceiveQC).
Сертификаты абстрактные (QC = множество голосов ≥ 2f+1), подписи не моделируются.
Pacemaker, верификация подписей, ограничение памяти — вне модели.

n = 3f+1, кворум = n − f = 2f+1. Нотация: `X ⪯ Y` — X предок-или-равен Y;
`conflict(X,Y)` = `X ⋠ Y ∧ Y ⋠ X`; `rank(B) = V(QC(B))`.

---

## Слой 0 — цель (safety)

- **I0 (agreement).** Нет двух конфликтующих закоммиченных блоков.
  `∀ b1, b2 ∈ (⋃ committed): ¬conflict(b1, b2)`
  Эквивалент через высоту: `b1.height = b2.height ⟹ b1 = b2`.
  Это то, что Apalache пытается опровергнуть; всё ниже — вспомогательное.

---

## Слой 1 — локальные структурные (дешёвые, ~индуктивны сами)

- **I1 (лок согласован с сертификатом).** `qc_lock ≠ ⊥ ⟹ certified(qc_lock.node) ∧ qc_lock.node = b_lock`.
  Ловит рассинхрон b_lock / qc_lock.

- **I2 (монотонность лока по view).** На любом шаге `qc_lock'.viewNumber ≥ qc_lock.viewNumber`.
  Лемма-помощник доказательства. Пишется как action-property / часть IndInv.

- **I3 (votedView монотонен и согласован).** `votedView` не убывает; голос во view v ⟹ `votedView ≥ v`.
  Машинный аналог «один голос за view».

- **I4 (qc_high — максимум по view).** `qc_high.viewNumber ≥ viewNumber любого обработанного QC`.
  Ловит баг #4 (если qc_high случайно ранжируется по высоте — падает).

- **I5 (b_exec монотонен).** На любом шаге `b_exec'.height ≥ b_exec.height`.
  Ловит откат b_exec (баг #3).

---

## Слой 2 — глобальные про сертификаты (сердцевина safety)

- **I6 (per-view uniqueness).** В одном view сертифицирован максимум один блок.
  `∀ qc1, qc2: qc1.viewNumber = qc2.viewNumber ⟹ qc1.node = qc2.node`
  = Lemma 1 / база индукции. Легко на BMC; для inductive нужен I9.

- **I7 (главный — lock ⟹ protection).** Машинный эквивалент леммы 4.1.
  ```
  если ∃ direct commit блока B во view v  (∃ QC(B)@v ∧ ∃ QC(child(B))@v+1),
  то ∀ валидного qc с qc.viewNumber ≥ v:  B ⪯ qc.node
  ```
  Центральный инвариант; из него I0 следует почти сразу. Тяжёлый, НЕ индуктивен как есть.

- **I8 (ancestry).** Каждый сертифицированный блок расширяет свой justify.
  `∀ certified b: b.justify.node ⪯ b`
  Следствие ancestry-проверки в onReceiveProposal; нужен в шаге доказательства.
  Забыта проверка ancestry (баг #2b) → I8 падает → I7 недоказуем.

---

## Слой 3 — вспомогательные (усиления, без которых I6/I7 не индуктивны)

- **I9 (голос ⟹ состояние голосующего).** Если честная r проголосовала за b во view v, то
  в тот момент `qc_lock(r).viewNumber ≤ b.justify.viewNumber` И `b.justify.node ⪯ b`.
  Мост между «существует QC» и «состояние локов»; без него I7 не индуктивен.

- **I10 (лок honest — на реальном QC).** Для честной r: `qc_lock(r)` — реально сформированный QC,
  ранга = `qc_lock(r).viewNumber` (не «из будущего», не выдуман). = I1+I2 явно для индукции.

**Индуктивный инвариант для подачи в Apalache:**
```
IndInv := I1 ∧ I2 ∧ I3 ∧ I5 ∧ I6 ∧ I8 ∧ I9 ∧ I10 ∧ I7
```
Проверяется `IndInv ∧ Step ⟹ IndInv'`. С первого раза, скорее всего, не пройдёт —
Apalache покажет ломающий переход, добавляешь недостающий конъюнкт. Это и есть докрутка.

---

## Порядок проверки (важнее списка)

1. **BMC на I0** без индукции, глубина 10–15, n=4. Цель — воспроизвести баги как
   контрпримеры (убери соседние-views → I0 падает трассой b1@1, c@2). Калибровка модели.
2. **BMC на I1–I8 по отдельности** — быстрая проверка на достижимых состояниях;
   тут вылезут #3/#4, если фиксы не внесены.
3. **Inductive invariant (IndInv)** — итеративно докручивая. Самый долгий шаг.

---

## Не брать в инварианты

- Liveness (`◇ progress`) — не инвариант, а temporal property под fairness. Отдельно.
- Верификация подписей / verifyQC / verifyShare — сертификат в модели абстрактный,
  валиден по построению. Проверяется кодом, не Quint.
- Ограничение памяти — про ресурсы, не про безопасность.

## Минимальный старт

Один инвариант с максимумом сигнала: **I6** (корректность голосования) + **I0** (цель).
На BMC сразу скажут, воспроизводится ли основной класс safety-багов. Дальше — к I7.
